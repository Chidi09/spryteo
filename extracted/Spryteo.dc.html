Documentation

Spryteo converts raster images and icons into clean, animateable SVG. Install it, then reach for whichever surface fits your workflow — CLI, HTTP API, library, or MCP.

Install

Requires Node 18 or newer. Install globally for the CLI, or as a dependency for the library.

$ npm install -g spryteo
# or, as a project dependency
$ npm install spryteo

Quick start — CLI

Point it at a raster file. It writes a grouped, animateable SVG next to the source.

$ spryteo ./icon.png --groups --out ./icon.svg
traced 1 path · 3 groups · 2.1 kb → ./icon.svg

HTTP API

POST an image, get SVG back. The body is the raw file; the response is image/svg+xml.

$ curl -X POST https://api.spryteo.dev/v1/convert \
    -H "content-type: image/png" \
    --data-binary @icon.png

Library

Import the async convert() function. It returns an SVG string plus the group map.

import { convert } from 'spryteo'

const { svg, groups } = await convert(buffer, {
  groups: true,
  simplify: 0.4,
})

MCP server

Register Spryteo as an MCP server and agents can convert icons in-conversation. Add this to your client config:

{
  "mcpServers": {
    "spryteo": { "command": "spryteo-mcp" }
  }
}
